# 내 계좌 상황실

토스증권 계좌를 매일 아침 점검하는 개인용 대시보드의 데이터 파이프라인입니다. 매수·매도를 권하지 않고, 선택지(추가 매수, 일부 매도, 보유, 현금)마다 쏠림·변동성·비용·세금이 어떻게 달라지는지 숫자로 보여 줍니다.

## 무엇을 계산하나

- **계좌 요약**: 평가금, 손익, 하루 변동(환율 포함 원화 기준), 계좌 전체 본전까지 필요한 상승률
- **판단 기준표**: 급변일(계좌 ±4%, 코스피·필라델피아 반도체 ±5%), 재검토 손실률, 최근 불리한 뉴스, 근거 점검선, VIX, 테마 쏠림
- **위험**: 최근 1년 주간 원화 수익률(수정종가)로 구한 공분산, 계좌 변동성, 종목별 위험 비중, 1년 중 최악의 3개월
- **쏠림 비교표**: 대표 지수·자산군 ETF와 보유 종목에 같은 금액을 넣었을 때의 계좌 변동성 변화를 현금 기준선과 비교하고, 4주 블록 부트스트랩 표본오차로 "현금과 비슷"을 판정
- **실질 노출**: ETF 안의 편입 종목까지 펼친 회사·계열별 비중
- **시뮬레이터 입력값**: 토스증권 수수료, 환전 비용, 국내 ETF·해외주식 세금

## 파일

| 파일 | 내용 |
|---|---|
| `positions.json` | 보유 종목과 수량, 평균단가 (예시 값) |
| `universe.json` | 비교 후보군과 시장 지표 목록 |
| `rules.json` | 판단 기준값 |
| `thesis.json` | 종목별 근거와 점검선 |
| `plan.json`, `journal.json` | 내 규칙, 결정 기록 |
| `research.json` | 뉴스·일정·금리·수수료·ETF 구성 조사 결과 |
| `collect.py` | 가격·지표 수집과 위험 계산 → `data/` |
| `build_static.py` | 조사 결과와 편집 파일 → `data/` |
| `page/index.html` | 대시보드 페이지 |

## 실행

```bash
python3 collect.py
python3 build_static.py
```

외부 패키지 없이 Python 3 표준 라이브러리만 씁니다. 가격은 Yahoo Finance, 미국 금리와 하이일드 스프레드는 FRED에서 받습니다.

## 실제 보유 내역 넣기

저장소의 `positions.json`은 예시 값입니다. 실제 보유 내역은 저장소에 커밋하지 말고 다음 중 하나로 넣으세요.

- **GitHub Actions**: 저장소 Settings → Secrets and variables → Actions에 `POSITIONS_JSON` 이름으로 `positions.json`과 같은 형식의 JSON을 등록합니다. 있으면 `collect.py`가 이 값을 씁니다.
- **로컬**: `POSITIONS_JSON` 환경변수를 지정하거나, 저장소 밖에 둔 파일을 씁니다.

`data/`에는 실제 보유 내역이 반영될 수 있어 `.gitignore`로 제외했습니다. Actions는 결과를 3일짜리 워크플로 아티팩트로만 남기므로, 이 저장소는 비공개로 두는 것을 권합니다.
